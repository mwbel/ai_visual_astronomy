# 藏历天文历算可视化工具

这是一个基于HTML5和JavaScript的交互式藏历天文历算可视化工具，实现了需求文档中提及的核心功能。

## 功能特性

### 🌟 核心功能
- **恒星日与太阳日差异计算**：精确展示两种时间系统的差异
- **朔望月周期可视化**：完整显示月相变化过程
- **二十八宿/二十七宿星座系统**：3D天球映射展示
- **藏历节气计算**：基于太阳黄经的精确定位
- **天体位置实时计算**：太阳、月亮位置的动态追踪

### 🎨 可视化展示
- **3D天球坐标系统**：支持赤道坐标、黄道坐标转换
- **多视角切换**：地心视角、日心视角、月心视角
- **时间轴控制器**：支持任意时期的天象回放
- **实时数据标注**：天体位置、角度、距离等参数显示

### 🎮 交互功能
- **藏历日期转换**：公历与藏历的双向转换
- **术语智能检索**：详细的天文术语解释系统
- **个性化设置**：观测地点、时区等参数配置
- **响应式设计**：支持桌面和移动设备

## 技术架构

### 前端技术栈
- **HTML5 + CSS3**：现代Web标准
- **JavaScript ES6+**：模块化开发
- **Three.js**：3D可视化渲染
- **Plotly.js**：数据图表展示

### 核心模块
1. **AstronomyCalculator**：天文计算引擎
2. **ThreeScene**：3D场景管理器
3. **UIControls**：用户界面控制器
4. **DataManager**：数据管理和缓存
5. **DemoDataProvider**：演示数据和增强功能

## 快速开始

### 1. 环境要求
- 现代浏览器（Chrome 90+、Firefox 88+、Safari 14+、Edge 90+）
- 支持WebGL的设备
- 网络连接（用于加载外部库）

### 2. 运行应用
1. 下载所有文件到本地目录
2. 使用Web服务器打开`index.html`（不能直接双击打开）
3. 推荐使用Python简单服务器：
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   ```
4. 在浏览器中访问 `http://localhost:8000`

### 3. 基本操作
- **鼠标拖拽**：旋转3D视角
- **滚轮缩放**：调整观察距离
- **左侧面板**：控制时间和显示模式
- **右侧面板**：查看实时数据和术语解释
- **底部时间轴**：快速跳转到特定日期

## 故障排除

### 常见问题
1. **页面空白**：检查浏览器控制台错误，确保使用Web服务器访问
2. **3D场景不显示**：检查WebGL支持，更新显卡驱动
3. **性能卡顿**：降低浏览器缩放比例，关闭其他标签页
4. **数据不准确**：这是演示版本，使用简化算法

### 调试模式
在浏览器控制台中输入以下命令启用调试：
```javascript
window.app.config.debug = true;
```
